# FCP Tools

Utilities, tools, and small apps for Final Cut Pro workflows.

## FCP7 Export Tool

[FCP7 Export Tool](https://github.com/macvfx/final-crack-pro) recovers legacy
Final Cut Pro 7 `.fcp` project files by exporting XML that can be used in a
modern recovery workflow for Final Cut Pro, DaVinci Resolve, or Adobe Premiere
Pro. The macOS release bundles its own Python runtime, so users do not need to
install or configure Python.

The application code originated in David Rice's MIT-licensed
[final-crack-pro](https://github.com/davidarice/final-crack-pro) project. The
macvfx fork adds the self-contained macOS application packaging and release
workflow while retaining the original license and third-party notices.

For background on moving older projects forward, see
[FCP7 to FCPX](https://macvfx.blog/2020/01/14/fcp7-to-fcpx/) on the macvfx blog.

## Related projects

- [FCPXML](https://github.com/macvfx/FCPXML) converts `.fcpxmld` bundles to
  standalone `.fcpxml` documents.
- [FCP Backup Manager](https://github.com/macvfx/FCP-Backup-Manager) archives
  and copies Final Cut Pro project backups to another destination.

More Final Cut Pro utilities may be collected here over time.
